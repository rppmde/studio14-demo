# Studio 14 by Arthur · v46

Static multilingual site. Open through a local HTTP server, for example `python3 -m http.server 8000`, then visit `/en/`, `/ru/` or `/hy/`.

v46 adds curated tattoo and piercing portfolios, links to further work on Instagram, and four piercing examples. The Tattoo page leads with the work and keeps Arthur’s introduction below. Shared card tracks align headings and body starts; the oral-piercing heading wraps.

This is a review package. Existing demo noindex/canonical settings remain. Booking is still a demonstration form; it does not send or store requests. No publication was performed.

Read VALIDATION.md for checks and limits. Uploaded works stay unassigned to individual tattoo artists. Piercing work comes from Vahagn with the permission confirmed by the client.
