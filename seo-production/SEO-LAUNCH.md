# Studio 14 SEO launch notes (production)

This repository is still a public demo and intentionally keeps `noindex,nofollow` plus a blocking root `robots.txt`. Do **not** copy those two demo directives into production.

## Production URL plan

English stays at the root to preserve the current English-first domain pattern. Russian uses `/ru/`; Armenian uses `/hy/`.

Examples:
- `https://studio14byarthur.com/`
- `https://studio14byarthur.com/tattoo/`
- `https://studio14byarthur.com/piercing/`
- `https://studio14byarthur.com/tattoo-removal/`
- `https://studio14byarthur.com/ru/tattoo/`
- `https://studio14byarthur.com/hy/tattoo/`

## Prepared in v7

- Unique titles and meta descriptions for EN/RU/HY.
- Self-canonical production URLs.
- Fully-qualified `hreflang` with self-reference and `x-default`.
- Open Graph and Twitter metadata.
- JSON-LD with `TattooParlor`, Service, Person, BreadcrumbList, ItemList and WebSite entities.
- Better image alt text and intrinsic image dimensions.
- Dedicated landing pages for tattoo, piercing, tattoo removal, Arthur and Vahagn.
- Internal linking from Home/Artists/Piercing/Tattoo to relevant pages.

## WordPress launch actions

1. Use one SEO owner. If Rank Math/Yoast generates titles, canonical, hreflang or schema, do **not** also hard-code duplicate tags in the theme. Configure the plugin using `seo-page-map.csv`.
2. Use Polylang (or equivalent) for language relationships. Confirm every EN/RU/HY page points to itself and both alternatives. Hreflang URLs must be absolute.
3. Production pages should be `index,follow`, except `/book/`, which should be `noindex,follow` because it is an action page, not a useful search landing page.
4. Replace the demo `robots.txt` with `seo-production/robots.txt`, or let WordPress generate an equivalent file.
5. Use the production sitemap generated by the SEO plugin. `seo-production/sitemap.xml` is the reference launch URL set. Submit the live sitemap in Google Search Console.
6. Keep English at `/` rather than moving it to `/en/` unless there is a strong reason. This reduces unnecessary migration from the current site.
7. Add 301 redirects for every old indexed URL that changes. `redirects-known.csv` contains only mappings that are safe now. Export all current indexed URLs from Search Console before launch and finish the map.
8. Keep `/tattoo-courses/` as the permanent English course URL. Redirect the legacy RU and HY course slugs to the new localized course URLs. Do not redirect `/services/` blindly because it currently covers both tattoo and piercing intents.
9. Validate final LocalBusiness/TattooParlor schema in Google Rich Results Test and Schema.org Validator after WordPress renders the final HTML.
10. Verify exact phone, email, opening-hours wording, tattoo-removal method/equipment, hygiene claims, artist bios/styles and the third resident artist before launch.
11. Replace the generic social share image with one dedicated 1200×630 Studio 14 image before launch.
12. Replace placeholder portfolio blocks with real work before indexing. Do not launch an empty Works page as a search landing page.
13. Set a square 48×48 or larger favicon/site icon in WordPress.
14. Connect Search Console and Analytics. Track successful booking submissions as a conversion event, not only pageviews.
15. After launch, inspect Home, Tattoo, Piercing, Removal, Studio and artist pages in Search Console URL Inspection and request indexing.

## Content backlog after launch

Do not create thin style pages just to target keywords. Add `/tattoo/blackwork/`, `/tattoo/realism/`, etc. only when each page has enough real Studio 14 work, a relevant artist, useful copy and a booking path.

FAQ is intentionally not part of this version. Useful questions can later live contextually on Tattoo, Piercing or Removal pages without a separate FAQ item in the main navigation.
